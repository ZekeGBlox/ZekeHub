# ZekeHub

roblox script hub, one key works on 60+ games. also got mass farms for adopt me and mm2 that you control from the website

website: https://zekehub.com
games: https://zekehub.com/games
buy a key: https://zekehub.com/pricing
discord: https://discord.gg/zekehub

## how to use

put your key in the quotes and execute

```lua
script_key = "" -- paste your key here
loadstring(game:HttpGet("https://zekehub.com/scripts/MainLoader.lua"))()
```

## mass farms

adopt me:
```lua
getgenv().script_key = "" -- paste your key here
loadstring(game:HttpGet("https://zekehub.com/scripts/AdoptMe/MassFarm.lua"))()
```

mm2:
```lua
getgenv().script_key = "" -- paste your key here
loadstring(game:HttpGet("https://zekehub.com/scripts/MM2/MassFarm.lua"))()
```

run it on as many accounts as you want, they all show up on your dashboard on the site (stats, configs, auto trade etc)
